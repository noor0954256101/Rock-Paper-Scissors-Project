# Rock Paper Scissors Game

A console-based Rock Paper Scissors game built with C++.

The player chooses the number of rounds, then plays against the computer. The computer generates its choices randomly, and the program determines the winner of each round and keeps track of the player's wins, computer wins, and draws.

At the end of the game, a final results screen displays the total rounds, win counts, draws, and the overall winner.

## Features

* Choose between 1 and 10 rounds
* Player vs Computer gameplay
* Random computer choices
* Round-by-round winner detection
* Score tracking
* Final game results
* Visual screen colors based on the winner
* Option to play again

## Concepts Used

* Enums
* Structures
* Functions
* Arrays
* Loops
* Conditional statements
* Random number generation
* Input validation
* Modular programming
